# Aurorium playtest downloads

Download Aurorium from the [public releases page](https://github.com/lauvogler/Aurorium-Downloads/releases). No GitHub account or Ren’Py installation is needed.

| Platform | Download | Open after downloading |
| --- | --- | --- |
| Android | `aurorium-0.8.3.2.apk` | Open the APK and confirm installation. |
| Windows | `Aurorium-0.8.3-pc.zip` | Extract the entire ZIP, then run `Aurorium.exe`. |
| Linux | `Aurorium-0.8.3-pc.zip` | Extract the ZIP, then run `Aurorium.sh`. |

Aurorium is a development playtest intended for adult players. These builds include the castle icon and the 0.8.3 combat interface.

Use the APK or PC ZIP under **Assets**. GitHub’s automatically generated “Source code” files contain only this download repository’s documentation.

Download future builds from this page. The current game’s optional update notice still uses the earlier private release channel.
